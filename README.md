# SEO · AEO 페이지 생성 규칙

웹서비스의 페이지를 만들 때 참고할 SEO·AEO·페이지네이션 규칙을 담은 프로젝트입니다. 현재는 공통 규칙을 준비한 단계이며, 웹사이트 구현 코드는 포함되어 있지 않습니다.

## 포함된 규칙

- 페이지별 메인 키워드, 검색 의도와 핵심 질문 설계
- 허브·상세·목록 페이지 구조와 내부 링크
- 제목, 본문, 직접적인 답변, 출처와 구조화 데이터
- 페이지네이션 URL, 이전·다음 링크와 페이지별 canonical
- 색인 정책, sitemap, 호스팅·배포 및 모바일 검증

전체 규칙은 [AGENTS.md](./AGENTS.md)에서 확인할 수 있습니다.
