# 연예인 섭외 웹서비스 · SEO · AEO 페이지 생성 규칙

연예인 섭외 웹서비스의 페이지를 만들 때 적용할 SEO·AEO·메타태그·페이지네이션 규칙을 담은 프로젝트입니다. 현재는 서비스에 맞춘 제작 규칙을 준비한 단계이며, 웹사이트 실행 코드는 아직 없습니다.

사용자가 운영하는 [메이드인헤븐 김용준 디렉터 블로그](https://blog.naver.com/madeinheavenkyj)를 근거로 기본 브랜드를 **메이드인헤븐**으로 설정했습니다. 가수·배우·MC·DJ·댄서·쇼호스트·강연자와 기업행사·지역축제·대학축제·브랜드 행사 안내를 반영합니다.

운영 도메인, 기술 스택, 실제 공개할 프로필 목록과 웹사이트 문의 방식은 미정입니다. 도메인은 추후 구매하며, 그 전에는 미리보기의 색인을 막고 경로와 콘텐츠 구조를 설계합니다.

## 포함된 규칙

- `연예인 섭외`, `가수 섭외`, `MC 섭외`, 인물별 섭외 등 페이지별 대표 키워드와 경로 설계
- 전체·분야별 목록, 개별 프로필, 행사별 안내, 비용·절차 가이드의 연결
- title·description·H1·Open Graph·canonical·robots 생성 규칙과 예시
- 직접적인 답변, 실제 출처·서비스 조건에 근거한 AEO 구성
- 같은 대표 키워드를 유지하는 페이지네이션과 실제 목록 기반 메타데이터
- 도메인 미정의 noindex 미리보기 및 운영 도메인 확정 후 전환 검증

전체 규칙은 [AGENTS.md](./AGENTS.md)에서 확인할 수 있습니다.

## 자료 반영 기준

[출처별 확인 기록](./SOURCES.md)에 운영 블로그의 서비스 소개와 추가 제공된 두 블로그의 참고 범위를 구분했습니다. 행사 조건, 견적 비교, 실제 출연 시간, 촬영·홍보 활용 범위 등을 질문과 가이드 구조에 반영했습니다. 다른 담당자의 연락처나 실적은 사용자 정보로 옮기지 않았습니다.

## 페이지네이션 예시

가수 목록의 대표 경로는 `/categories/singers/`, 다음 구간은 `/categories/singers/?page=2`입니다. 2페이지 제목은 `가수 섭외 목록 - 2페이지 — 메이드인헤븐`으로 구분하고, 운영 도메인이 확정되면 해당 2페이지의 절대 URL을 canonical로 사용합니다. 페이지마다 다른 분야 키워드를 배정하거나 모두 1페이지를 canonical로 지정하지 않습니다.

## 다음 제작 단계

새 사이트에 공개할 서비스 범위·실제 프로필·문의 방법을 확정하고 기술 스택을 선택한 뒤 이 규칙을 웹사이트 코드에 구현합니다. 현재 파일 작성은 실제 페이지의 메타태그 출력·검색 노출·배포 검증 완료를 의미하지 않습니다.
